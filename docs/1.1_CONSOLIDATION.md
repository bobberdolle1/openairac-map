## 3. Target registry & unified installer

- `TargetDescriptor` registry expanded: multi-platform install roots
  with `%VAR%`/`~` expansion (X-Plane 12/11 Steam+retail, Little
  Navmap per-OS DB dirs, MSFS 2020/2024 Store+Steam Community paths,
  PMDG classic dirs), detection rules, honest support states.
- `GenericTargetInstaller`: transactional install/rollback for
  CustomData and Subdirectory strategies.
- CLI: `target list|detect|install|rollback|update-all`. `update-all`
  exports the world once per family and updates every detected target
  with per-target rollback on failure - never mixes worlds.
  E2E verified: 5 targets updated from real 2609 DB, 1 skipped.
- Installer hardening (found by live verification + red team):
  - cross-volume swap fixed (copy into destination volume first;
    Windows ERROR_NOT_SAME_DEVICE bug eliminated);
  - swap-loop failures roll back automatically;
  - commit retains journal + backup → `target rollback` undoes the
    last successful install byte-identically;
  - Committed journal is an undo feature, not a crash: recovery only
    rolls back non-Committed journals; new installs supersede the old
    journal/backup;
  - rollback routing fixed per target (X-Plane journal schema).
