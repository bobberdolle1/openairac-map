# Application & Navigation Data Updates

## 1. Application Updates
* Go to **Help > Check for Updates...**
* OpenAIRAC Map checks the official release channel for new releases.
* If an update is available, download the installer and run it to upgrade smoothly. All your settings and flight plans will be preserved.

---

## 2. AIRAC Navigation Updates
* Go to **Tools > OpenAIRAC Data Manager...**
* When a new 28-day AIRAC cycle is released, click **Install Latest AIRAC** to download and activate it with zero downtime.
