# OpenAIRAC Map Installation Guide

## 1. Windows Installation

### Option A: Setup Installer (Recommended)
1. Download `OpenAIRAC-Map-1.0.0-Windows-x64-Setup.exe` from the official release page.
2. Run the installer and follow the on-screen steps.
3. Launch **OpenAIRAC Map** from the Start Menu or Desktop shortcut.

### Option B: Portable ZIP
1. Download `OpenAIRAC-Map-1.0.0-Windows-x64-Portable.zip`.
2. Extract the archive into any folder of your choice (e.g. `D:\OpenAIRAC-Map`).
3. Run `openairac-map.exe`. All settings and caches will be kept within the portable folder.

---

## 2. Linux Installation

1. Download `OpenAIRAC-Map-1.0.0-x86_64.AppImage`.
2. Make the file executable:
   ```bash
   chmod +x OpenAIRAC-Map-1.0.0-x86_64.AppImage
   ```
3. Run `./OpenAIRAC-Map-1.0.0-x86_64.AppImage`.

---

## 3. macOS Installation

1. Download `OpenAIRAC-Map-1.0.0-macOS.dmg`.
2. Open the disk image and drag **OpenAIRAC Map** into your `Applications` folder.
3. Launch OpenAIRAC Map from Applications or Spotlight.
