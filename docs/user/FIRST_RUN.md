# First-Run Setup & Onboarding Guide

When you launch OpenAIRAC Map for the first time, the **Setup Wizard** will guide you through initial configuration:

## 1. Welcome Screen
Confirms that OpenAIRAC navigation data, charts, live weather, and VATSIM awareness are enabled by default without commercial subscriptions.

## 2. Simulator Detection
The wizard automatically detects installed flight simulators (X-Plane 12, X-Plane 11, MSFS).
* If detected: verify the path and click Next.
* If not detected or running standalone: select "Use Standalone Mode".

## 3. Navigation Data Installation
Select your preferred initial navigation data bundle:
* **World Open Bundle (Recommended)**: Complete global airports, runways, navaids, fixes, and procedures.
* **United States FAA Bundle**: Complete US nationwide CIFP terminal procedures.
* **Europe Open Bundle**: European airspace datasets.

Click **Install OpenAIRAC Data Now** to automatically download, verify checksums, and activate your navigation database.

## 4. Optional Providers
If you have a commercial Navigraph FMS database in your simulator, you can optionally enable it as a secondary provider. OpenAIRAC remains active by default.

## 5. Live Feeds & Finish
Verifies connectivity to NOAA AviationWeather.gov and VATSIM network services. Click **Finish** to open the map and create your first flight plan.
