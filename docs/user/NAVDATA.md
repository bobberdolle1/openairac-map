# Navigation Data & AIRAC Cycles in OpenAIRAC Map

## 1. Where Does the Data Come From?

OpenAIRAC compiles official, public aeronautical publications:
* **FAA Aeronautical Information Services**: Complete US CIFP terminal procedures, airway routes, and fixes.
* **DGAC France / SIA**: French aerodromes, runways, radio navaids, and route network under Etalab Licence Ouverte v2.0.
* **DFS Germany**: Open geodata under GeoNutzV-OpenData.
* **OurAirports**: Worldwide community airport and runway registry.

---

## 2. Managing AIRAC Cycles

To check for navigation data updates or roll back to a previous cycle:
1. Go to **Tools > OpenAIRAC Data Manager...**
2. Click **Check for Data Updates**.
3. If a new AIRAC cycle is available, click **Install Latest AIRAC**.
4. To revert an update, click **Rollback to Previous AIRAC**.
