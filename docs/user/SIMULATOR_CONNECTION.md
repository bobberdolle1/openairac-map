# Simulator Connection Guide

## 1. Connecting to X-Plane 12 / 11

1. Start X-Plane 12 or 11.
2. In OpenAIRAC Map, go to **Tools > Flight Simulator Connection**.
3. Select **Connect to X-Plane automatically**.
4. Once connected, your aircraft will appear on the moving map with live track and altitude.

---

## 2. Connecting to MSFS (2020 / 2024)

1. Start Microsoft Flight Simulator.
2. In OpenAIRAC Map, select **Connect to MSFS via SimConnect**.
3. The moving map will track your live aircraft position in real-time.
