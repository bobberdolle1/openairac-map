# OpenAIRAC Map Platform Support Matrix (v1.0.0)

## 1. Supported Operating Systems & Packages

| Operating System | Architecture | Maturity Status | Distribution Formats |
| :--- | :---: | :---: | :--- |
| **Windows 11 / 10** | `x86_64` (64-bit) | **SUPPORTED** | One-Click Setup Installer (`OpenAIRAC-Map-1.0.0-Windows-x64-Setup.exe`), Portable ZIP (`OpenAIRAC-Map-1.0.0-Windows-x64-Portable.zip`) |
| **Linux (Ubuntu, Fedora, Arch)** | `x86_64` (64-bit) | **SUPPORTED** | Universal AppImage (`OpenAIRAC-Map-1.0.0-x86_64.AppImage`), Tarball (`.tar.gz`) |
| **macOS (Apple Silicon & Intel)** | `arm64` / `x86_64` | **SUPPORTED** | Application Bundle / DMG (`OpenAIRAC-Map-1.0.0-macOS.dmg`, unsigned community build) |

---

## 2. Integrated Product Experience

* **Zero-Terminal Setup**: Automatic discovery of simulator scenery paths and one-click initial OpenAIRAC navdata installation.
* **Standalone EFB Mode**: Fully usable on a laptop or secondary screen without a flight simulator running.
* **Upstream Coexistence**: Completely isolated configuration paths (`OpenAIRAC/OpenAIRAC Map`) preventing conflicts with original Little Navmap installations.
