## Checklist & Verification

### 1. Cycle discovery → preload → activation is automatic and verified
- **Implemented**: cycle catalog + state machine (`Discovered` → `Preloaded` → `Active` → `Superseded`/`Expired`/`RolledBack`), `Scheduled`/`Observed` orchestration, transactional `observe_cycles_conn`.
- **Verified**: `test_cycle_catalog_roundtrip_and_transitions`, `test_late_sync_observe_and_atomicity`, `test_temporal_airac_activation_boundary`, `test_redteam_temporal_attacks`.
- **Temporal Invariants**: Time-driven activation via UTC instants; query instants strictly respect `valid_from <= t`. Cycle 2609 is preloaded on 2026-08-19, remaining inactive until its confirmed effective instant `2026-09-03T09:01:00Z`.

### 2. Reconciliation coverage includes every entity class OpenAIRAC decodes
- **Implemented**: airports, runways, navaids, waypoints, airway legs with exact, probable, continuity, and regionless matchers, regional authority rules, and sha256 conflict deduplication.
- **Empirical result (2609)**: 2,916 candidate pairs, 1,420 exact matches, 0 conflicts.

### 3. Bundles are signed, reproducible, and installable
- **Reproducible**: deterministic content-addressed bundles (`ManifestCore` sha256 binding).
- **Signed**: Ed25519 `sign_bundle` / `verify_bundle_with_trust`. Embedded production trust root: `a8f2ca4e06872bf4`. Production install path fails closed on unsigned bundles (`--allow-unsigned` is explicit dev escape).
- **Installable**: staged, validated, backup-swapped, journal-driven with automatic rollback on failure.

### 4. Rollback works at publication, cycle, and artifact level
- **Verified**: publication rollback (re-publication of historical state, idempotent), cycle rollback (`rollback_cycle`), and artifact rollback (`rollback_bundle`).

### 5. Data quality gates block releases on unresolved errors
- **Enforced**: `build_bundle` refuses stores with validation errors.
- **Automated gate**: `openairac release-gate` + `scripts/release-gate.sh` machine-enforces 0 validation errors, publication audit cleanliness, procedure reference integrity, bundle determinism, signature fail-closed, and installer post-validation.

### 6. Aviation semantics fidelity
- **Airports/runways**: PA/PG records (13,316 airports, 8,149 runway pairs in 2608; 13,307 airports, 8,172 runways in 2609), reciprocal designator pairing, tens-of-feet lengths, DDDMMSS.ss coordinates.
- **Navaids & ILS**: PI records decoded for localizer position, frequency, runway, front course (cols 52-55), direct glideslope angle (cols 88-90), station declination, and elevation. Glideslopes and localizers enriched with PF approach associations.
- **Procedure geometry**: RF arc derivation (`derive_rf_arc`), holds (HA/HF/HM), procedure diagnostics.
