# IVAO Online Network Integration

OpenAIRAC Map integrates with the official IVAO network via the Whazzup tracking API.

## 1. Provider Capabilities
- **Pilots**: Live aircraft positions, callsigns, flight plans, altitudes, ground speeds, and headings.
- **Air Traffic Control**: Tower, Ground, Delivery, Approach, and Center controllers with active frequencies and ATIS.
- **VATSIM & IVAO Coexistence**: Dual network monitoring with distinct network badges (`[VATSIM]`, `[IVAO]`) and non-colliding client identity tracking.
